# 作品简介

> GOAI 赛道一【新智基座｜Agent Infra】· 选题方向四：金融风控与理赔自动化（信贷风控与贷后处置）
> 队伍名称：`Durandal` ｜ 成员：`李家宝`

---

**项目名称**：信衡 CreditSentry — 贷后风险处置多 Agent 闭环系统

**问题与场景**：银行小微与对公贷后管理四大痛点——预警海量、筛查成本高；核查跨工商/司法/征信/流水多系统，证据分散耗时；报告与处置靠人工，标准不一、经验难复用；监管要求可追溯可复核，证据链不足。

**核心解决方案**：以 AgentTeams 为基点，构建 1 Manager + 1 TeamLeader + 6 Worker 闭环：信号聚合→取证→定性⇄质疑→分级处置→审计回流。TeamLeader 用 SOP 五阶段状态机路由，LLM 只做阶段内判定、不决定流程。能力沉淀为 14 个 Skill（领域自研＋官方用云 Skills），外部经 4 个 MCP 接入。

**创新点**：①内控即拓扑：把「不相容职务分离」编译为权限矩阵，Agent 数由权限等价类推导；②证据账本＋对抗裁决：无证据不决策、质疑官不可跳过，专治误杀；③闸门 L0–L3：不可逆动作永不自动执行，带幂等键与回滚点。

**开放 / 复用价值**：开源拆分法则、CreditSkill Spec、14 个 Skill、4 个 MCP 契约与案例数据集；可平移至保险核赔、供应链金融、反洗钱调查。

**当前进展**：架构与 Skill 清单定稿，PoC 跑通「风险成立」「误报驳回」两链路，产出 Trace、日志、处置意见书与审计报告；全用合成与公开数据。
